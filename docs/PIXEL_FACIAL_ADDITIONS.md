Use the Face tab to select them. The eyes retain the independent iris colour control; nose and mouth shading follow skin colour. All three use the existing pixel rendering profile. Existing IDs and images are unchanged.

Generated with the built-in OpenAI image tool as individual components, without third-party reference artwork. Exact prompts and generation provenance are recorded in each item descriptor. The canonical PNGs are referenced by content hash there; there is no second artwork pack.

Coverage: front-facing portrait components only. These are not LPC imports, animated sprites, or full-body artwork. Mixing with illustrated heads/hair is supported but intentionally produces mixed visual styles. Editable layered artist source files are not available for these generated PNGs.

Reviewed together on gentle oval and angular heads at the workshop's portrait/profile/icon sizes. Automated checks cover all 4,480 current head/eyes/nose/mouth combinations for numeric identity; browser checks additionally compare rendered combinations. This does not replace artistic review of every possible accessory combination.
