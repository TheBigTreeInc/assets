# Portrait library 5 native data clients

The codec handles format 2/library 5, eleven categories and seven RGB colours.
example-game-bindings.json demonstrates every component ID, including the new
feminine-focused head, eye, nose and mouth options. Replace these bindings with
your game's IDs. The verified single-pack downloader supports offline caches.

Native renderers must implement the specified neck/garment/head planes,
jawBoundary, optional neckAsset, facialHair, scars, opacity and per-part scale
and offset. The supplied codec/downloader do not provide a native renderer or
update the earlier neon-control game. See ../../docs/PORTRAIT_SYSTEM_SPEC.md.
